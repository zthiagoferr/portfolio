# Efeitos cinematográficos

O visual mantém o fundo escuro, iluminação volumétrica, fitas digitais decorativas, revelação de títulos, reflexos em cards e textura cinematográfica suave. Não há Liquid Glass nesta edição.

Os efeitos são de apresentação; não criam painéis, APIs nem backend adicionais. Os ajustes de largura buscam evitar rolagem horizontal indevida. Consulte [README-CINEMATIC-PREMIUM.md](README-CINEMATIC-PREMIUM.md) para as animações de decodificação e parallax.

Para testar: `npm install`, `npm start` e http://localhost:4200/.
