# Cinematic Premium — efeitos visuais

Esta edição combina a base cinematográfica de largura ajustada com:

- **Decodificação de títulos:** caracteres decorativos aparecem ao revelar títulos de seção; na versão aprimorada o efeito dura aproximadamente 1,9 s e pode ser reativado passando o mouse por cima.
- **Parallax multicamadas:** grade, rede neural, fitas e iluminação respondem a movimentos do ponteiro e à rolagem em velocidades distintas.
- **Card 3D Python:** a fotografia pode ser girada horizontalmente ao arrastar, revelando um terminal com **digitação simulada** de código Python. Enter permite interação por teclado.

A versão conserva o tema claro/escuro, PT/EN, o Portfolio Terminal e o layout responsivo. Os efeitos adicionais respeitam a preferência por redução de movimento (`prefers-reduced-motion`).

A animação do terminal **não executa scripts Python**. Esta versão **não inclui Liquid Glass**.

Teste em http://localhost:4200/ com `npm start`; para reiniciar arquivos no cache use `Ctrl+Shift+R`.
