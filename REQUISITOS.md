# Landing Page Profissional

Criar uma landing page/portfólio profissional pessoal preparada para hospedagem estática no GitHub Pages e GitLab Pages.

## Objetivo

Apresentar minha trajetória profissional e meus conhecimentos técnicos, com destaque crescente para desenvolvimento com Python e agentes de Inteligência Artificial.

A página deve transmitir que tenho conhecimentos práticos em:

- Python;
- desenvolvimento em Python;
- configuração e desenvolvimento de agentes de IA;
- arquitetura multiagente;
- criação e configuração de Skills para agentes;
- MCP (Model Context Protocol);
- definição e configuração de papéis especializados para agentes;
- uso de um agente Orquestrador para coordenar outros agentes;
- conceitos de Arduino;
- automações e integração de tecnologias.

## Formação e cursos

Apresentar uma seção de cursos/certificações.

Tenho certificados/conhecimentos em:

- Conceitos de Python;
- Desenvolvimento em Python;
- Conceitos de Arduino.

Estou atualmente concluindo:

- Desenvolvimento com Agentes de IA utilizando Python.

IMPORTANTE:
o curso "Desenvolvimento com Agentes de IA utilizando Python" ainda não deve ser apresentado como concluído ou certificado. Mostrar claramente como "Em conclusão", "Em andamento" ou expressão equivalente.

Não inventar:
- instituições;
- datas;
- carga horária;
- números de certificados;
- tecnologias não informadas;
- experiência profissional não fornecida.

Caso algum dado pessoal necessário não esteja disponível, usar conteúdo neutro facilmente substituível ou TODO claramente identificado.

## Destaque técnico: Agentes de IA

A página deve explicar de maneira profissional e compreensível que possuo conhecimento em construção/configuração de ambientes de agentes especializados.

Exemplos de responsabilidades que conheço:

- Orquestrador:
  coordena agentes especializados e consolida resultados;

- Analista:
  trabalha requisitos, regras, ambiguidades e critérios de aceite;

- Arquiteto:
  define arquitetura e estratégia técnica;

- Engenheiro:
  implementa código, testes e correções;

- Revisor:
  realiza revisão independente;

- Pesquisador:
  consulta documentação e fontes externas quando necessário.

Também destacar conhecimentos em:

- Skills especializadas;
- permissões e isolamento de responsabilidades;
- MCPs;
- integração de ferramentas;
- workflows multiagente;
- validação e revisão de resultados.

Não transformar a landing page em documentação técnica.
Esses conhecimentos devem ser apresentados visualmente e de forma acessível a recrutadores, clientes e profissionais de tecnologia.

## Direção visual

Quero aparência moderna, profissional e tecnológica.

Prioridades:

- ótima primeira impressão;
- identidade ligada a desenvolvimento e IA;
- excelente tipografia;
- responsividade;
- boa hierarquia visual;
- animações discretas quando fizerem sentido;
- acessibilidade;
- bom desempenho;
- visual profissional sem exageros.

Evitar aparência de template genérico.

## Estrutura sugerida

O projeto pode decidir a melhor arquitetura visual, mas deve contemplar conteúdo equivalente a:

- Hero;
- Sobre;
- Competências;
- Agentes de IA / Arquitetura Multiagente;
- Cursos e Certificações;
- Projetos;
- Contato.

## Projetos

Preparar uma seção de projetos que possa posteriormente receber links para projetos reais do GitHub e GitLab.

Não inventar projetos que eu não informei.

Pode utilizar cards placeholder claramente identificados como conteúdo a preencher posteriormente.

## GitHub e GitLab

A implementação deve ser compatível com publicação estática.

Preparar o projeto para posterior publicação em:

- GitHub Pages;
- GitLab Pages.

NÃO realizar:
- git push;
- publicação;
- deploy;
- criação de repositório remoto.

## Qualidade

A solução deve:

- funcionar localmente;
- ser responsiva;
- possuir HTML semântico quando aplicável;
- considerar acessibilidade;
- evitar dependências desnecessárias;
- possuir estrutura de projeto organizada;
- permitir manutenção fácil;
- não conter secrets;
- não depender de backend sem necessidade.

## Liberdade técnica

O Orquestrador e seus agentes devem decidir a tecnologia adequada com base nesses requisitos e nas Skills disponíveis.

Não existe obrigação de usar React, Flutter, Streamlit ou qualquer framework específico.

Prefira a solução mais adequada para uma landing page estática profissional.

## Resultado esperado

Entregar a primeira versão funcional da landing page no diretório do projeto.

Ao terminar, informar:

- arquitetura escolhida;
- agentes utilizados;
- Skills utilizadas;
- arquivos criados;
- como executar localmente;
- testes/validações realizados;
- limitações ou TODOs;
- preparação necessária para GitHub Pages;
- preparação necessária para GitLab Pages.

Não faça commit, push ou deploy.
